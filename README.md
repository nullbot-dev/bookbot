# BookBot: Telegram-бот онлайн-записи

Бот записи на время для барбершопа, салона красоты, мастера маникюра, массажиста или любого бизнеса, где клиент приходит к конкретному специалисту в конкретное время.

Демо настроено под барбершоп «Борода»: 4 услуги, 2 мастера, график Пн–Сб 10–21, Вс 11–18. Под другой бизнес бот перенастраивается правкой одного файла `bot/salon.py`.

## Возможности

**Для клиента**
- запись в несколько нажатий: услуга → мастер (или «любой свободный») → день → свободное время → подтверждение;
- показывается только **действительно свободное** время: учитываются график, длительность услуги и уже занятые окна мастера;
- если выбран «любой мастер», бот сам подберёт свободного;
- телефон спрашивается один раз (кнопкой «Отправить мой номер» или вручную) и запоминается;
- **напоминания** за сутки и за 2 часа до визита с кнопками «Приду» и «Отменить запись»;
- «Мои записи»: список предстоящих визитов и отмена (не позже чем за 2 часа);
- услуги с ценами и контакты.

**Для администратора**
- уведомление о каждой новой записи и отмене с кнопкой «Отменить»;
- `/schedule`: расписание на день с переключением дней ◀️ ▶️ и отменой записей (клиент получает уведомление);
- `/stats`: клиенты, предстоящие записи, записи на сегодня, проведённые визиты, отмены, выручка;
- `/export`: все записи в CSV, который сразу открывается в Excel.

**Надёжность**
- защита от двойной записи: если два клиента одновременно выбрали одно время, второму бот предложит другое;
- нельзя записаться в прошлое или ближе чем за час до визита;
- прошедшие записи автоматически отмечаются как проведённые;
- время считается в часовом поясе салона, где бы ни был сервер.

## Стек

Python 3.11+, aiogram 3, SQLite (`aiosqlite`), FSM для пошаговой записи, фоновая задача для напоминаний.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows; на Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # Linux/macOS: cp .env.example .env
```

Заполните `.env`: `BOT_TOKEN` (от [@BotFather](https://t.me/BotFather)) и `ADMIN_IDS` (ваш id, узнать у [@userinfobot](https://t.me/userinfobot)).

```bash
python -m bot
```

## Как адаптировать под клиента

Всё в файле `bot/salon.py`:
- `NAME`, `CONTACTS`, `TIMEZONE` — название, адрес и часовой пояс;
- `SERVICES` — услуги: название, длительность в минутах, цена;
- `MASTERS` — мастера;
- `WORK_HOURS` — график по дням недели (`None` — выходной);
- `SLOT_STEP_MIN`, `DAYS_AHEAD`, `MIN_LEAD_MIN`, `CANCEL_LIMIT_MIN` — шаг сетки, горизонт записи, минимальное время до визита, срок отмены.

## Структура

```
bot/
├── __main__.py      # точка входа, запуск напоминаний
├── salon.py         # настройки салона (меняется под клиента)
├── slots.py         # расчёт свободного времени
├── db.py            # SQLite: клиенты, записи, статистика
├── reminders.py     # напоминания и закрытие прошедших записей
├── texts.py         # тексты сообщений
├── keyboards.py     # кнопки
├── states.py        # шаги записи (FSM)
├── notify.py        # уведомления администраторам
└── handlers/
    ├── user.py      # запись, «Мои записи», отмена
    └── admin.py     # расписание, статистика, экспорт
```
